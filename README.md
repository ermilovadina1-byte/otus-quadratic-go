# Квадратное уравнение на Go

Учебное решение первого ДЗ курса OTUS «Архитектура и шаблоны проектирования». Реализация выполнена по шагам TDD: сначала падающий тест для нового поведения, затем минимальная правка кода и повторный запуск всех тестов.

## Запуск

```sh
go test ./...
go vet ./...
```

Команды выполняются из этой папки. В CI выполняются те же проверки.

## Контракт

`Solve(a, b, c) ([]float64, error)` возвращает действительные корни `a*x*x + b*x + c = 0` с учетом кратности. При `D < -Epsilon` список пуст. При `abs(D) < Epsilon` возвращаются два одинаковых корня. При `D >= Epsilon` возвращаются два корня в порядке `+sqrt(D)`, затем `-sqrt(D)`.

`Epsilon = 1e-5`. Если `abs(a) < Epsilon`, функция возвращает `ErrNotQuadratic`. Для `NaN` или бесконечности в любом коэффициенте возвращается `ErrNonFiniteCoefficient`. Если вычисление дискриминанта выходит за диапазон `float64`, возвращается `ErrUnrepresentableResult`.

Это учебный контракт с фиксированным абсолютным допуском из задания. Он не задает универсально корректную численную политику для коэффициентов любого масштаба.

## Проверенные циклы TDD

| Случай | Красный результат до реализации | Зеленый результат после правки |
| --- | --- | --- |
| Нет действительных корней | Возвращался `[0]`. | Пустой список. |
| Два разных корня | Возвращался `[0]`. | `[1, -1]`. |
| Кратный корень | Возвращался `[0]`. | `[-1, -1]`. |
| `a` близок к нулю | Ошибки не было. | Возвращается ошибка. |
| Ненулевой `D < Epsilon` | Возвращались два разных близких корня. | Корень считается кратным. |
| `NaN` и бесконечности | Ошибки не было для каждого коэффициента. | Возвращается ошибка. |
| Переполнение дискриминанта | Возвращался `NaN` как корень. | Возвращается ошибка. |
